# Platforms Agents 🚀

**Platforms Agents** is an AI-powered social media scheduling, automation, and content management platform. Effortlessly schedule posts, analyze performance, and manage multiple social media channels from a unified dashboard.

---

## ✨ Features

- 📅 **Smart Scheduling:** Plan and auto-publish content across multiple social platforms.
- 🤖 **AI Automation:** Generate post descriptions, ideas, and visual assets with AI.
- 📊 **Analytics & Insights:** Track post engagement and performance metrics in real-time.
- 👥 **Team Collaboration:** Invite team members to review, comment, and manage schedules.
- 🔌 **API & Webhooks:** Integrate seamlessly with third-party tools and workflows.

---

## 🛠️ Tech Stack

- **Monorepo:** PNPM Workspaces
- **Frontend:** Next.js (React), Tailwind CSS
- **Backend:** NestJS, Node.js
- **Database & ORM:** PostgreSQL, Prisma
- **Background Tasks:** Temporal
- **Notifications:** Resend
